About AI Plant Disease Detector

AI Plant Disease Detector is an intelligent web application developed to identify diseases in plant leaves using Deep Learning techniques.

Farmers and agricultural students can upload a leaf image and instantly detect whether the plant is healthy or affected by disease.

The application is built using Python, Flask, CNN (Convolutional Neural Network), HTML, CSS and JavaScript.
